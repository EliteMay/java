① 今日の主役

Java での意味

言葉意味
変数と型変数は、値を入れておく名前付きの入れ物です。型は、その入れ物に入れられる値の種類で、int（整数）・double（小数）・String（文字列）・boolean（true か false）などがあります。変数を作るときに型を書きます。int count = 3; double price = 198.7; String name = "ノート";
演算子と文字列演算子は、計算や比較をする記号です（+ - * / %、== < >、&& など）。文字列は、" で囲んだ文字の並び（String）で、+ でつないだり、substring で一部を切り出したりできます。int total = 150 * 3; String msg = "合計 : " + total + "円";
条件分岐条件が成り立つかどうかで、実行する処理を分ける文。if ／ else if ／ else と switch があります。if (score >= 80) { ... } else if (score >= 60) { ... } else { ... }
配列同じ型の値を決まった数だけ並べ、1つの変数名でまとめて扱う仕組み。1つ1つの値は 0 から始まる番号（添字）で指定します。作ったあとで数は変えられません。int[] nums = {80, 65, 90}; nums[0] // 1つ目の 80
繰り返し同じ処理を、条件を満たしている間くり返し実行する文。for・拡張 for・while・do-while があります。for (int i = 0; i < nums.length; i++) { ... }

たとえで言うと

配列は「0号室から始まる部屋の並び」、繰り返しは「全部屋の見回り」

3部屋のマンションの部屋番号は、0・1・2。3号室はありません。

配列は「0号室から始まる部屋の並び」、繰り返しは「全部屋の見回り」

配列は、同じ型の値を並べて、1つの名前で持つものです。1つ1つの値は「何号室か」を表す番号で取り出します。番号は 0 から数えます。

繰り返し（for 文）は、0号室から順に1部屋ずつ見回るのに使います。部屋が3つでも1000でも、書くコードは同じです。

部屋の数と、最後の部屋の番号はずれます。3部屋なら最後は2号室です。ここを1つ間違えると、無い部屋を見に行ってプログラムが止まります。③の解説で、実際に止めてみます。

たとえJava では
マンション配列　int[] nums = {80, 65, 90};
部屋番号添字　nums[0] nums[1] nums[2]
部屋の数nums.length（ここでは 3）
全部屋を順に見回るfor (int i = 0; i < nums.length; i++)
3号室無い。見に行くと ArrayIndexOutOfBoundsException

なぜ必要か

変数と型計算の途中の値や入力された値を覚えておき、あとで使うためです。型を決めておくと、整数の所に文字を入れるような間違いを、実行する前に見つけられます。
演算子と文字列値を計算したり比べたりして、その結果を人が読める文にして表示するためです。
条件分岐値によって違う動きをさせるためです。条件分岐が無いと、どんな値でも同じ処理しかできません。
配列同じ種類の値が多いとき、1つずつ別の変数にすると、数だけ変数が増えてまとめて扱えないからです。
繰り返し同じ処理を何行も書かずに済み、値の数が変わってもコードは同じで済むからです。

使う場面

変数と型商品の価格・在庫数・名前を持っておくとき。合計を計算しながら足していくとき。
演算子と文字列税込み金額の計算、点数が合格点以上かの判定、「合計 : 660円」のような表示を作るとき。
条件分岐点数で評価を分ける、在庫が0なら「売り切れ」と表示する、入力が正しいかを調べるとき。
配列クラス全員の点数、1週間の売上のように、同じ種類の値を並べて持つとき。
繰り返し配列の値を全部表示する、合計する、九九の表を作るとき。

package lesson02;

public class Recall {

        System.out.println(5 % 2);                         // 予想：　① あまり

        {
            int i = 5;
            System.out.println(i++);                       // 予想：　③ 使ってから増やす

            System.out.println(a == c);                    // ⑤ 同じ物か
            System.out.println(a.equals(c));               // ⑤ 同じ中身か

        System.out.println("--- if ---");
        {
            int score = 85;
            if (score >= 80) {                             // ⑥ 上から順に調べる
                System.out.println("優");

                System.out.println("良");
            } else {
                System.out.println("再テスト");
            }

③ 解説

写したコードを、行の右の番号の順に説明します。説明する所のコードを、それぞれの頭に抜き出しています。よくある間違いも一緒に見ます。

1　変数と型（①②）

System.out.println("--- 割り算 ---");
System.out.println(5 / 2);                         // 予想：　① int どうしの割り算
System.out.println(5.0 / 2);                       // 予想：　① double の割り算
System.out.println(5 % 2);                         // 予想：　① あまり

System.out.println("--- キャスト ---");
double price = 198.7;
int rounded = (int) price;                         // ② キャスト
System.out.println(rounded);                       // 予想：

5 / 2 は 2、5.0 / 2 は 2.5 と出ます。int どうしの割り算は、結果も int になるので、小数が消えます。5.0 のように片方が double（小数を入れる型）なら、double の割り算になります。% は割り算のあまりで、5 % 2 は 1 です。

(int) price のように、型の名前を丸括弧で囲んで値の型を変える書き方をキャストと言います。198.7 を int にするので、198 と出ます。切り捨てで、四捨五入ではありません。なぜ (int) を書くのか。double を int に入れると小数が失われるので、Java はそのままでは入れさせないからです。

2　演算子と文字列（③④⑤）

System.out.println("--- ++ ---");
{
    int i = 5;
    System.out.println(i++);                       // 予想：　③ 使ってから増やす
    System.out.println(i);                         // 予想：
    System.out.println(++i);                       // 予想：　③ 増やしてから使う
    i += 3;
    System.out.println(i);                         // 予想：
}

5 ／ 6 ／ 7 ／ 10 と出ます。i++ も ++i も i を1増やしますが、i++ はいまの値を使ってから増やし、++i は増やしてから使います。println(i++) は 5 を表示してから 6 にし、println(++i) は 7 にしてから表示します。i += 3 は i = i + 3 と同じです。

System.out.println("--- substring ---");
{
    String s = "商品コード:A-1024";
    System.out.println(s.substring(s.indexOf(":") + 1));   // ④ 切り出す
}

Java は文字の位置を 0 から数えます。s.indexOf(":") は : の位置 5 を返し、s.substring(n) は位置 n の文字から後ろを全部切り出します。なぜ + 1 するのか。indexOf が返した位置には、コロンそのものが立っているからです。欲しいのは、その次の文字からです。

System.out.println("--- == と equals ---");
{
    String a = "ノート";
    String b = "ノート";
    String c = new String("ノート");
    System.out.println(a == b);                    // ⑤ 同じ物か
    System.out.println(a == c);                    // ⑤ 同じ物か
    System.out.println(a.equals(c));               // ⑤ 同じ中身か
}

true ／ false ／ true と出ます。== は「同じ物か」、equals は「同じ中身か」を見ます。コードに直接書いた同じ文字は Java が1つを使い回すので、a == b は true です。new String("ノート") は文字列を新しく作る書き方で、中身が同じでも別の物になるので、a == c は false です。文字列を比べるときは equals を使います。new は第4回で扱います。

3　条件分岐（⑥）

System.out.println("--- if ---");
{
    int score = 85;
    if (score >= 80) {                             // ⑥ 上から順に調べる
        System.out.println("優");
    } else if (score >= 60) {
        System.out.println("良");
    } else {
        System.out.println("再テスト");
    }
}

if ／ else if ／ else は上から順に調べ、最初に当てはまった所だけが動きます。85 は score >= 80 に当てはまるので「優」だけが出ます。score を 70 にすると「良」、45 にすると「再テスト」と出ます。なぜ 80以上を先に書くのか。60以上を先に書くと、85 もそこで当てはまって「良」になるからです。

同じ分け方は switch でも書けます。switch は1つの値を見て、一致した case から動き、break; で抜けます。どれにも当たらなければ default が動きます。「80以上」のような範囲はそのままでは書けないので、score / 10 で10点ごとの番号（85 なら 8）にしてから分けます。

int score = 85;
switch (score / 10) {
    case 10:
    case 9:
    case 8:
        System.out.println("優");
        break;
    case 7:
    case 6:
        System.out.println("良");
        break;
    default:
        System.out.println("再テスト");
}

4　繰り返し（⑦⑧⑨）

System.out.println("--- for ---");
{
    int sum = 0;                                   // ⑦ for の外に用意する
    for (int i = 1; i <= 10; i++) {                // ⑦ for の3つの部分
        sum += i;
    }
    System.out.println(sum);
}

for の丸括弧の中は、; で区切った3つの部分です。最初に1回だけ動く int i = 1、毎回調べる条件 i <= 10、1周ごとの最後に動く i++ の順に書きます。i が 1 から 10 まで変わるあいだ sum += i を繰り返すので、55 と出ます。なぜ sum を for の外に書くのか。for の中で宣言すると、1周ごとに作り直されて 0 に戻り、for が終わると消えるからです。

System.out.println("--- while と do-while ---");
{
    int count = 0;
    while (count > 0) {                            // ⑧ 先に調べる
        System.out.println("while");
        count--;
    }
}
{
    int count = 0;
    do {                                           // ⑧ 先に動く
        System.out.println("do-while");
        count--;
    } while (count > 0);
}

do-while の1行だけが出ます。while は入る前に条件を調べるので、count が 0 だと1回も動きません。do-while は動いてから調べるので、必ず1回動きます。count を両方とも 3 にすると、while と do-while が3回ずつ出て、差は消えます。

count を2回宣言していますが、{ } で囲んであるのでぶつかりません。{ } の中で宣言した変数は、その中だけで使えます。ほかの所も、同じ名前の変数がぶつからないように { } で囲んでいます。

System.out.println("--- 九九 ---");
{
    for (int dan = 1; dan <= 9; dan++) {           // ⑨ 二重ループ
        for (int retsu = 1; retsu <= 9; retsu++) {
            System.out.printf("%3d", dan * retsu);
        }
        System.out.println();                      // ⑨ 内側が終わってから改行
    }
}

for の中に for を書く形を二重ループと言います。外側の dan が1つ進むあいだに、内側の retsu が 1 から 9 まで回ります。System.out.printf("%3d", 値) は3桁ぶんの幅をとって数字を表示し、改行はしません。なぜ改行を内側の for の後ろに書くのか。1行に9個並べ終わってから改行するためです。内側に書くと、1個ごとに改行されて81行になります。

5　配列（⑩⑪）

System.out.println("--- 拡張for ---");
{
    int[] scores = {80, 65, 90};                   // ⑩ 配列
    for (int s : scores) {                         // ⑩ 拡張for文
        System.out.println(s);
    }
}

int[] scores = {80, 65, 90}; は配列です。3つの int を 0番・1番・2番の順に並べて、scores という1つの名前で持ちます。点数が何人分に増えても、scores という名前は1つのままで、番号で1人ずつ取り出せます。

for (int s : scores) は拡張for文です。番号を使わずに、配列の中身を1つずつ取り出して s に入れます。: の左の型には、配列の中身の型を書きます。

普通の for と比べる。⑩の拡張for文を、⑦と同じ普通の for で書くと次のようになります。上が普通の for、下が⑩の拡張for文です。どちらも 80・65・90 の順に表示します。

同じ色の所が、同じ仕事をしている

普通の for では、①番号 i を 0 から数えることと、②i 番目の値を s に入れることを、自分で書いています。拡張for文は、この①と②を Java が代わりにする書き方です。for (int s : scores) は「scores の中身を1つずつ s に入れて、{ } の中を繰り返す」と読みます。

1周ずつ追うと、次のようになります。拡張for文でも、s に入る値と順番はまったく同じです。違うのは、i が見えないことだけです。

普通の for の i条件 i < scores.lengths に入る値表示
1周目00 < 3 → truescores[0] → 8080
2周目11 < 3 → truescores[1] → 6565
3周目22 < 3 → truescores[2] → 9090
次33 < 3 → false（入らずに終わる）―

拡張for文の動きが分からなくなったら、普通の for に書き直して、この表のように i と s を1周ずつ書き出すと追えます。

やりたいこと使う for理由
全部を順に見る（表示する・足す・比べる）拡張for文番号を書かないので、範囲の外を見る間違いが起きない
何番目かを使う（「0行目」と表示する、隣と比べる）普通の for拡張for文には i が無い
配列の中身を書き換える普通の fors は取り出した値を入れた別の変数なので、s に入れ直しても配列は変わらない

④の ScoreReport は全員を順に見るだけなので、拡張for文で書きます。次の⑪で普通の for を使っているのは、「0行目の合計」のように番号を表示するためです。

System.out.println("--- 二次元配列 ---");
{
    int[][] table = { {1, 2, 3}, {4, 5}, {6, 7, 8, 9} };   // ⑪ 二次元配列
    for (int i = 0; i < table.length; i++) {
        int total = 0;
        for (int j = 0; j < table[i].length; j++) {   // ⑪ i 行目の個数
            total += table[i][j];
        }
        System.out.println(i + "行目の合計 : " + total);
    }
}

int[][] table は二次元配列です。配列の中に配列が入っていて、table[0] が {1, 2, 3}、table[1] が {4, 5} です。外側は table.length（行の数 3）で回し、内側は table[i].length（i 行目の個数）で回します。なぜ table[i].length なのか。行ごとに個数が 3個・2個・4個と違うからです。

よくある間違い：for の条件を <= で書く。

Recall.java（間違いあり）

package lesson02;

public class Recall {
    public static void main(String[] args) {
        int[] nums = {80, 65, 90};
        for (int i = 0; i <= nums.length; i++) {           // <= と書いた

        }
    }

ScoreReport.java（4つの課題を書いたもの）

package lesson02;

public class ScoreReport {
    public static void main(String[] args) {
        int[] scores = {82, 55, 91, 68, 77, 49, 100, 73, 60, 38};

        // 課題① 受験者数と合計点
        int sum = 0;
        // ここに for を書いて、sum に全部足す
        for (int s : scores) {
            sum += s;
        }
        System.out.println("受験者数 : " + scores.length + " 人");
        System.out.println("合計点   : " + sum + " 点");

        // 課題② 平均点（小数第1位まで）
        double average = (double) sum / scores.length;
        System.out.printf("平均点   : %.1f 点%n", average);

        // 課題③ 最高点と最低点
        int max = scores[0];
        int min = scores[0];
        for (int s : scores) {
            if (s > max) {
                max = s;
            }
            if (s < min) {
                min = s;
            }
        }
        System.out.println("最高点   : " + max + " 点");
        System.out.println("最低点   : " + min + " 点");

        // 課題④ 60点未満の人数と、その点数の一覧
        int retest = 0;
        String list = "";
        for (int s : scores) {
            if (s < 60) {
                retest++;
                list += ", " + s;
            }
        }
        System.out.println("再テスト : " + retest + " 人（" + list.substring(2) + "）");
    }
}

実行結果

受験者数 : 10 人 合計点 : 693 点 平均点 : 69.3 点 最高点 : 100 点 最低点 : 38 点 再テスト : 3 人（55, 49, 38）

課題①③④は、どれも「for (int s : scores) で1人ずつ取り出して、何かをする」形です。取り出したあとにすることが、足す・比べる・つなぐ、と変わるだけです。
