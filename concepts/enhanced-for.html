拡張for文と通常のfor文

配列の値を順番に読むだけなら拡張for。番号が必要なら通常for。

まず結論

for (int score : scores) は「scoresの要素を1つ取り出してscoreに入れる」を繰り返す。score は配列の番号ではなく、要素の値。

コードと結果で確認

まず実際にどう動くかを見て、その理由を下で整理する。

Main.java（そのまま実行できる例）
public class Main {
    public static void main(String[] args) {
        int[] scores = {60, 80, 100};
        int sum = 0;

        for (int score : scores) {
            sum += score;
            System.out.println("取り出した値: " + score);
        }
        System.out.println("合計: " + sum);
    }
}
実行結果
取り出した値: 60
取り出した値: 80
取り出した値: 100
合計: 240

1行ずつ考えると

  1. 最初の周回でscores[0]の値60がscoreに入る。
  2. 次は80、次は100。配列の最後まで自動で進む。
  3. 各周回でsum += scoreを実行。sumは0→60→140→240になる。

ここで間違えやすい

よくある勘違いscore は取り出した値を受け取る変数。score = 0; としても、元の scores の要素は0にならない。配列を書き換えたいときは添字を使う。

通常forは「添字（番号）」も使える

比較用のコード（必要部分を抜粋）
int[] scores = {60, 80, 100};
for (int i = 0; i < scores.length; i++) {
    scores[i] += 5; // 配列そのものを更新
}
System.out.println(scores[1]); // 85

i は0→1→2と変わる番号。scores[i] なら配列の要素を直接変更できる。番号がいらない集計なら拡張forで十分。breakは両方のforで使える。

30秒で理解チェック

int[] a = {3, 6, 9}; に対し、for (int x : a) { x += 1; } のあと、a[0] は何？

答えと理由を開く

3のまま。 x は要素の値を受け取るだけ。a[0] を変えるなら添字を指定して更新する。
