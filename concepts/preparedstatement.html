PreparedStatementと更新処理

検索と更新はどう違う？ ?・setInt・executeUpdateを理解する。

まず結論

SQLの ? は後から値を渡すための場所。setInt(1, id) の1は最初の?、executeUpdate() の戻り値は影響を受けた行数。追加・更新・削除に使う。

コードと結果で確認

処理の流れを先に捉えてから、各行の意味を確認しよう。

JDBC抜粋：接続済みのconnが必要
String sql = "UPDATE products SET price = ? WHERE id = ?";
try (PreparedStatement ps = conn.prepareStatement(sql)) {
    ps.setInt(1, 180);  // 1つ目の ? に価格
    ps.setInt(2, 3);    // 2つ目の ? にID
    int updated = ps.executeUpdate();
    System.out.println("更新行数: " + updated);
}
実行結果・前提
更新行数: 1（ID=3の行が存在する場合）

1行ずつ考えると

  1. UPDATE は既存の行を書き換えるSQL。WHERE id = ? で対象を絞る。
  2. setInt(1,180) は1つ目の ? の値。0番ではなく1番から始まる。
  3. executeUpdate() はSELECTと違い、変更された行数を返す。該当するIDがなければ0になる。

ここで間違えやすい

よくある勘違いexecuteQuery() は主にSELECTで結果の行を受け取る。INSERT/UPDATE/DELETEでは通常 executeUpdate()。WHERE を忘れると意図せず全件更新される。

INSERTとDELETEの使い分け

比較用のコード（必要部分を抜粋）
// 新しい商品を追加
String insert = "INSERT INTO products(id, name) VALUES (?, ?)";
// 商品を削除
String delete = "DELETE FROM products WHERE id = ?";

どのSQLも入力値を文字列連結するのではなく、PreparedStatementに値を設定する。上の比較はSQL文字列の例で、接続と実行処理は省略。

30秒で理解チェック

価格を更新するSQLに ? が2つある。setInt(2, 5) で設定するのはどちらの ? ？

答えと理由を開く

2つ目。 ? の番号は1始まり。SQLに書いた順番で設定する。
