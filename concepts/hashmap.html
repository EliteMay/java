HashMapで数を集計する

Mapは「名前 → 件数」を覚える。putの仕組みを理解すると集計が分かる。

まず結論

Mapのput(key,value)は値を登録・上書きするだけ。既存の値に1を足したいなら、getやgetOrDefaultで今の件数を取る必要がある。

コードと結果で確認

まず実際にどう動くかを見て、その理由を下で整理する。

Main.java（出現回数を集計）
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        String[] sold = {"ノート", "ペン", "ノート"};
        Map<String, Integer> count = new HashMap<>();

        for (String item : sold) {
            int before = count.getOrDefault(item, 0);
            count.put(item, before + 1);
        }
        System.out.println(count.get("ノート"));
        System.out.println(count.get("ペン"));
    }
}
実行結果
2
1

1行ずつ考えると

  1. 最初のノートは未登録なので、getOrDefault("ノート",0)が0を返す。putで1を登録。
  2. ペンも未登録なので1を登録。
  3. 2回目のノートでは前の1を取り出し、1+1で2に更新する。

ここで間違えやすい

よくある勘違いcount.put(item, +1) は「1を入れ直す」という意味。+1 だけでは「現在の値に足す」処理にはならない。またgetは存在しないキーでnullを返すので、getOrDefaultが便利。

ArrayListとHashMapの違い

比較用のコード（必要部分を抜粋）
// Listは順番で取り出す
List<String> names = new ArrayList<>();
names.add("A");
System.out.println(names.get(0));

// Mapはキーで取り出す
Map<String, Integer> stock = new HashMap<>();
stock.put("A", 3);
System.out.println(stock.get("A"));

上の比較コードを実行する場合、java.util.List、ArrayList、Map、HashMapをimportする。HashMapは挿入した順番を保証しない。

30秒で理解チェック

ノートが3回登場するとき、ループ内で毎回map.put("ノート", 1)したら最後はいくつ？

答えと理由を開く

1。 putは既存の値を上書きするだけ。3にするには今の件数に1を足す。
