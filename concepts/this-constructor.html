thisとコンストラクタ

同じ名前のフィールドと引数は、どうやって区別する？

まず結論

this は「いま作っている・操作しているインスタンス自身」を指す。this.name はフィールド、name は受け取った引数。

コードと結果で確認

まず実際にどう動くかを見て、その理由を下で整理する。

Main.java（コンストラクタで初期値を設定）
public class Main {
    static class Product {
        String name;
        int price;

        Product(String name, int price) {
            this.name = name;
            this.price = price;
        }

        void show() {
            System.out.println(name + ": " + price);
        }
    }

    public static void main(String[] args) {
        Product a = new Product("りんご", 120);
        a.show();
    }
}
実行結果
りんご: 120

1行ずつ考えると

  1. new Product("りんご",120) で新しいインスタンスが作られる。
  2. 同時にProduct(String name,int price) というコンストラクタが実行される。
  3. this.name = name; で、受け取った値をそのインスタンスのフィールドに保存する。

ここで間違えやすい

よくある勘違いコンストラクタの名前はクラス名と同じ。void Product(...) とすると戻り値なしの普通のメソッドになり、コンストラクタではなくなる。this はstaticメソッドの中では使えない。

同じクラスから2つ作っても値は別

比較用のコード（必要部分を抜粋）
Product a = new Product("りんご", 120);
Product b = new Product("みかん", 80);
a.price = 150;
a.show(); // りんご: 150
b.show(); // みかん: 80

a と b は別インスタンスなので通常のフィールドは別々に持つ。クラスは設計、インスタンスは実物。

30秒で理解チェック

Product(String name) { this.name = name; } の左の name はどこに保存される？

答えと理由を開く

そのProductインスタンスのフィールド。 左の this.name と右の引数 name を分けて考える。
