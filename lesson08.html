① 今日の主役

Java での意味

言葉意味
コレクション複数のオブジェクトをまとめて扱うためのクラスの集まり（java.util）。配列と違い、数を決めずに作り、追加・削除に合わせて大きさが変わります。順番に並べる List、キーと値の組で持つ Map などがあります。List<Product> products = new ArrayList<>(); Map<String, Integer> stocks = new HashMap<>();
List（ArrayList）入れた順に並べて持つコレクションです。add で足し、get(番号) で取り出し、size() で数を数えます。ArrayList は List の実装クラスです。List<Product> products = new ArrayList<>(); products.add(p); products.get(0)
Map（HashMap）キー（名札）と値の組で持つコレクションです。put(キー, 値) で入れ、get(キー) で取り出します。HashMap は Map の実装クラスです。Map<String, Integer> stocks = new HashMap<>(); stocks.put("ノート", 10); stocks.get("ノート")

たとえで言うと

コレクションは「伸びる棚」と「名札つきの引き出し」

配列は、作るときに仕切りの数を決めた箱です。コレクションは、入れた分だけ伸びます。

コレクションは、数を決めずに使える入れ物。並べるのが List、名札で引くのが Map

第2回の配列は「3つ分」と決めて作ります。4つ目の商品が来ても、入れる所がありません。お店の商品は増えたり減ったりするので、数を先に決められない場面のほうが多いです。

そこで使うのがコレクションです。数を決めずに作り、入れた分だけ伸びる入れ物の総称です。今日はその中から2つを使います。

List は伸びる棚です。入れた順に並び、左から0番、1番…と数えます。Map は名札つきの引き出しです。名札（キー）を見て、その引き出しを直接開けます。

たとえJava では
仕切りの数が決まった箱配列　new Product[3]
伸びる棚List　new ArrayList<>()
棚の左から0番、1番…products.get(0)
名札つきの引き出しMap　new HashMap<>()
名札を見て開けるbyId.get(2)　名札が 2 の中身を取り出す

なぜ必要か

コレクション配列は作るときに数を決める必要があり、あとから増やせないからです。
List（ArrayList）数が決まっていない物を、順番どおりに並べて持つためです。
Map（HashMap）番号ではなく、名前や ID から1件を直接取り出すためです。

使う場面

コレクション増えたり減ったりする商品の一覧（List）。ID や名前から1件を探したいとき（Map）。
List（ArrayList）商品の一覧のように、あとから足したり、順に全部表示したりするもの。
Map（HashMap）商品名から在庫数を調べる、ID から商品を探すとき。

今日のゴールは、この棚と引き出しに商品を入れて、取り出せるようになることです。まず写します。

Product.java　入れ物に入れる商品

package lesson08;

public class Product {
    private static int count = 0;   // 作った商品の数（全体で1つ）

    private int id;
    private String name;
    private int price;
    private int stock;

    public Product(int id, String name, int price, int stock) {
        this.id = id;
        this.name = name;
        this.price = price;
        this.stock = stock;
        count++;
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public int getPrice() { return price; }
    public int getStock() { return stock; }

    public void setPrice(int price) {
        if (price < 0) {
            System.out.println("価格に負の値は設定できません");
            return;
        }
        this.price = price;
    }

    public void setStock(int stock) {
        if (stock < 0) {
            System.out.println("在庫に負の値は設定できません");
            return;
        }
        this.stock = stock;
    }

    public void show() {
        System.out.println(id + " / " + name + " / " + price + "円 / 残り" + stock + "個");
    }

    public static int getCount() { return count; }
}

Main.java　入れ物を使うほう

package lesson08;

import java.util.ArrayList;                                   // ① import
import java.util.HashMap;                                     // ① import
import java.util.List;                                        // ① import
import java.util.Map;                                         // ① import

public class Main {
    public static void main(String[] args) {
        List<Product> products = new ArrayList<>();                  // ② List を作る
        products.add(new Product(1, "ボールペン", 150, 30));         // ③ 足す
        products.add(new Product(2, "ノート", 220, 10));             // ③ 足す
        products.add(new Product(3, "消しゴム", 100, 50));           // ③ 足す

        System.out.println("件数 : " + products.size());             // ④ 数える
        System.out.println("0番目 : " + products.get(0).getName());  // ④ 取り出す
        for (Product p : products) {                                 // ⑤ 全部回す
            p.show();
        }

        Map<Integer, Product> byId = new HashMap<>();         // ⑥ Map を作る
        for (Product p : products) {
            byId.put(p.getId(), p);                           // ⑦ 名札を付けて入れる
        }
        Product found = byId.get(2);                          // ⑦ 名札で引く
        System.out.println("ID 2 : " + found.getName());
    }
}

2　List を作って、商品を足す（②③）

Main.java（抜き出し）

public static void main(String[] args) {
    List<Product> products = new ArrayList<>();           // ② List を作る
    products.add(new Product(1, "ボールペン", 150, 30));  // ③ 足す
    products.add(new Product(2, "ノート", 220, 10));      // ③ 足す
    products.add(new Product(3, "消しゴム", 100, 50));    // ③ 足す

}

List<Product> products = new ArrayList<>(); で、商品を入れる List を1つ作ります。<Product> は「中に入れるのは Product だけ」という指定で、この書き方をジェネリクスと呼びます。右の <> は左と同じなので中を省略できます。Product 以外のものを入れようとすると、その時点でエラーにしてくれます。

左の List は第7回のインタフェースで、ArrayList はそれを実装したクラスです。受ける側を List にしておくと、あとで別の実装に替えても使う側を書き換えずに済みます。

add で後ろに1つ足します。足すたびに List が伸びます。なぜ List にするのか。数を決めずに作れるからです。何件になるか前もって分からなくても、来た分だけ入れられます。

配列で持つと、どうなるか。第2回の配列で同じことをして、4つ目を入れようとした形です。

エラーメッセージ（Eclipse）

Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3 at lesson08.Main.main(Main.java:9)

new Product[3] で作った配列には、[0] [1] [2] の3つしか場所がありません。products[3] に入れようとした9行目で、プログラムが止まります。エラー文の Index 3 out of bounds for length 3 は「長さ3の配列に、3番は無い」という意味です。写経のコードのとおり List にすれば、4つ目も add を1行足すだけで入ります。

ここで出た言葉ArrayIndexOutOfBoundsException　配列の範囲の外の番号を使ったときに出るエラー。このように実行中に止まるエラーの扱いは、次回扱います

Main.java（抜き出し）

public static void main(String[] args) {

    System.out.println("0番目 : " + products.get(0).getName());  // ④ 取り出す

size() は入っている数、get(0) は0番目を取り出します。配列の length と [0] に当たる操作です。List には [ ] が使えないので、メソッドで書きます。番号は配列と同じく0から始まり、最後は size() - 1 番です。

products.get(0).getName() は左から読み、get(0) で取り出した商品の getName() を呼んでいます。

拡張for文は、第2回の配列と同じ書き方で、入れた順に1つずつ取り出します。List は入れた順番を覚えているので、表示も入れた順になります。

4　Map を作る（⑥）

Main.java（抜き出し）

名札（キー）と中身（値）を組にして入れる Map を作ります。<Integer, Product> は「名札は整数、中身は Product」という指定です。

なぜ Map を使うのか。ID で一発で引けるようにするためです。List で ID 2 を探すと前から順に見ていくことになりますが、Map は名札から直接たどれます。

Integer は int をクラスとして包んだもので、ラッパークラスと呼びます。< > の中には参照型（クラスなど）しか書けないので、int ではなく Integer と書きます。

よくある間違い：< > の中に int と書く。名札は整数なので、⑥を Map<int, Product> と書いた形です。Product は写したままです。

⑦の byId.put(p.getId(), p) では、getId() が返す int が自動で Integer に包まれます。byId.get(2) の 2 も同じです。この仕組みをオートボクシングと言います。

5　名札を付けて入れ、名札で引く（⑦）

Main.java（抜き出し）

public static void main(String[] args) {
    // （中略）
    for (Product p : products) {
        byId.put(p.getId(), p);                           // ⑦ 名札を付けて入れる
    }
    Product found = byId.get(2);                          // ⑦ 名札で引く
    System.out.println("ID 2 : " + found.getName());
}

put(キー, 値) で名札を付けて入れ、get(キー) で名札から取り出します。商品の ID（getId()）を名札にしておけば、get(2) で ID 2 の商品がすぐ出ます。

同じ名札でもう一度 put すると、前の中身は消えて新しい中身に置き換わります（上書き）。無い名札で get すると、エラーにはならず null（何も入っていない）が返ります。名札があるかは、containsKey(キー) が true / false で返します。

なぜ一覧は List で出すのか。商品名を名札にした Map を作り、入れた順に一覧を出そうとした形です。

        products.add(new Product(5, "のり", 120, 25));

        // ここに、在庫が少ない商品を入れる空の List（名前は low）を作る
        List<Product> low = new ArrayList<>();

        // ここに拡張for文を書き、在庫が20個より少ない商品だけ low に足す
        for (Product p : products) {
            if (p.getStock() < 20) {
                low.add(p);
            }
        }

        System.out.println("在庫が少ない商品 : " + low.size() + "件");
        // ここに、low の中身を1つずつ show() で表示する
        for (Product p : low) {
            p.show();
        }
    }
}

実行結果

在庫が少ない商品 : 2件 2 / ノート / 220円 / 残り10個 4 / 定規 / 180円 / 残り5個
「空の List を作る → 条件に合うものだけ add する」は、絞り込みの型です。このあとの回でも何度も出てきます。

package lesson08;

import java.util.HashMap;
import java.util.Map;

public class SalesMain {
    public static void main(String[] args) {
        String[] sold = {"ノート", "ボールペン", "ノート", "消しゴム", "ノート", "ボールペン"};
        Map<String, Integer> count = new HashMap<>();

        // ここに拡張for文を書き、sold の名前を1つずつ数える
        for (String name : sold) {
            if (count.containsKey(name)) {
                count.put(name, count.get(name) + 1);
            } else {
                count.put(name, 1);
            }
        }

        System.out.println("ノート : " + count.get("ノート") + "個");
        System.out.println("ボールペン : " + count.get("ボールペン") + "個");
        System.out.println("消しゴム : " + count.get("消しゴム") + "個");
    }
}

実行結果

ノート : 3個 ボールペン : 2個 消しゴム : 1個
表示は get で名札を指定して取り出しているので、書いた順に出ます。keySet() で回すと、③解説の5のとおり順番は約束されません。

この回に出た言葉です。覚えるためではなく、分からなくなったときに引くための表です。

言葉読み方意味
コレクションこれくしょん数を決めずに使える入れ物の総称。List や Map のこと
Listりすと入れた順に並べる入れ物。番号（0から）で取り出せます
ArrayListあれいりすとList を実装したクラス。new ArrayList<>() で作ります
Mapまっぷ名札（キー）と中身（値）を組にして入れる入れ物。名札で直接取り出せます
HashMapはっしゅまっぷMap を実装したクラス。new HashMap<>() で作ります。並び順は約束しません
キーきーMap の名札。同じキーは1つしか持てず、同じキーで put すると上書きされます
値あたいMap で、キーに結び付けて入れる中身
addあどList の後ろに1つ足すメソッド
getげっとList では番号で、Map ではキーで1つ取り出すメソッド
sizeさいず入っている数を返すメソッド。配列の length に当たります
putぷっとMap にキーと値を組にして入れるメソッド
containsKeyこんていんずきーMap にそのキーがあるかを true / false で返すメソッド
keySetきーせっとMap のキーを全部まとめたもの。拡張for文で回せます
importいんぽーと別のパッケージにあるクラスを使うための宣言。ファイルの上のほうに書きます
ジェネリクスじぇねりくす<Product> のように、入れ物に入れる型を指定する書き方
基本データ型きほんでーたがたint double boolean char など、クラスではない型（第2回）
ラッパークラスらっぱーくらす基本データ型をクラスとして包んだもの。int に対する Integer など
Integerいんてじゃーint を包んだクラス。比べるときは equals を使います
オートボクシングおーとぼくしんぐint と Integer を、Java が自動で包んだり戻したりする仕組み
インタフェースいんたふぇーすクラスが持つべきメソッドを決めた約束ごと。List はこれで、ArrayList が実装しています（第7回）
拡張for文かくちょうふぉーぶんfor (Product p : products) の形。中身を1つずつ取り出します（第2回）
ArrayIndexOutOfBoundsException―配列の範囲の外の番号を使ったときに出るエラー
