① 今日の主役

Java での意味

言葉意味
PreparedStatement値を入れる所を ? にした SQL を先に用意し、あとから setInt・setString などで値を入れて実行するための仕組み（java.sql）。入れた値は SQL の文ではなく値として扱われます。String sql = "DELETE FROM products WHERE id = ?"; PreparedStatement ps = con.prepareStatement(sql); ps.setInt(1, id);
追加・更新・削除（INSERT・UPDATE・DELETE）表に行を足す INSERT、行の値を変える UPDATE、行を消す DELETE の3つの SQL です。Java からは executeUpdate() で実行し、変わった行の数が返ります。INSERT INTO products (name, price, stock) VALUES (?, ?, ?) UPDATE products SET name = ?, price = ?, stock = ? WHERE id = ? DELETE FROM products WHERE id = ?

たとえで言うと

PreparedStatement は「空欄のある注文書」

注文書の形は先に決まっていて、空欄には値だけを書き込みます。

PreparedStatement は「空欄のある注文書」。空欄に入るのは値だけ

第11回で、SQL を「倉庫への注文書」にたとえました。今日の注文書には空欄があります。形は先に印刷されていて、書く人は空欄を埋めるだけです。注文書の形そのものは変えられません。

PreparedStatement は、この空欄のある注文書です。SQL の形を先に決め、値を入れる所を ? で空けておきます。あとから setString や setInt で、1つ目の空欄、2つ目の空欄…と値を入れて送ります。第11回の7つの手順で飛ばした「? に値を入れる」が、これです。

空欄に入るのは値だけです。名前に ' が入っていても、注文書の形は崩れません。今日は空欄を使って、1つ探す・追加・更新・削除をします。

入荷・変更・撤去の3種類の注文書。どれも executeUpdate() で出し、変わった行数が返る

注文書には種類があります。棚に新しく入れる「入荷の注文書」（追加 INSERT）、値札を書き換える「変更の注文書」（更新 UPDATE）、棚から下げる「撤去の注文書」（削除 DELETE）です。

なぜ必要か

PreparedStatement値を安全に SQL へ入れるためです。値を文字列でつなぐと、' などで SQL が壊れたり、SQL インジェクションで悪用されたりします。
追加・更新・削除（INSERT・UPDATE・DELETE）表のデータを読むだけでなく、アプリから書き換えるためです。

今日のゴールは、この注文書を使って、商品を追加・更新・削除できるようになることです。まず写します。

Product.java　商品（第5回と同じ）

package lesson12;

public class Product {
    private static int count = 0;   // 作った商品の数（全体で1つ）

    private int id;
    private String name;
    private int price;
    private int stock;

    public Product(int id, String name, int price, int stock) {
        this.id = id;
        this.name = name;
        this.price = price;
        this.stock = stock;
        count++;
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public int getPrice() { return price; }
    public int getStock() { return stock; }

    public void setPrice(int price) {
        if (price < 0) {
            System.out.println("価格に負の値は設定できません");
            return;
        }
        this.price = price;
    }

    public void setStock(int stock) {
        if (stock < 0) {
            System.out.println("在庫に負の値は設定できません");
            return;
        }
        this.stock = stock;
    }

    public void show() {
        System.out.println(id + " / " + name + " / " + price + "円 / 残り" + stock + "個");
    }

    public static int getCount() { return count; }
}

ProductDao.java　表の出し入れ（今日はここに4つ足す）

package lesson12;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class ProductDao {
    private static final String URL = "jdbc:mysql://localhost:65534/stock";
    private static final String USER = "root";
    private static final String PASSWORD = "pass";

    // 全部の商品を読む（第11回と同じ）
    public List<Product> findAll() throws SQLException {
        List<Product> list = new ArrayList<>();
        String sql = "SELECT id, name, price, stock FROM products ORDER BY id";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                list.add(new Product(rs.getInt("id"), rs.getString("name"),
                                     rs.getInt("price"), rs.getInt("stock")));
            }
        }
        return list;
    }

    // ID で1つ探す。無ければ null を返す
    public Product findById(int id) throws SQLException {
        String sql = "SELECT id, name, price, stock FROM products WHERE id = ?";   // ① ?
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);   // ② 1つ目の ? に入れる
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return new Product(rs.getInt("id"), rs.getString("name"),
                                       rs.getInt("price"), rs.getInt("stock"));
                }
            }
        }
        return null;   // ③ 無かった
    }

    // 追加する。変わった行数を返す
    public int insert(Product p) throws SQLException {
        String sql = "INSERT INTO products (name, price, stock) VALUES (?, ?, ?)";   // ④ id は書かない
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());   // ② 文字列は setString
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            return ps.executeUpdate();   // ⑤ 変わった行数
        }
    }

    // 更新する。変わった行数を返す
    public int update(Product p) throws SQLException {
        String sql = "UPDATE products SET name = ?, price = ?, stock = ? WHERE id = ?";   // ⑥ WHERE
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            ps.setInt(4, p.getId());   // ⑥ 4つ目は WHERE の ?
            return ps.executeUpdate();
        }
    }

    // 削除する。変わった行数を返す
    public int delete(int id) throws SQLException {
        String sql = "DELETE FROM products WHERE id = ?";   // ⑥ WHERE
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            return ps.executeUpdate();
        }
    }
}

③ 解説

写したコードを、行の右の番号の順に説明します。説明する所のコードを、それぞれの頭に抜き出しています。よくある間違いも一緒に見ます。

間違いの形の実行結果は、どれも最初の3件から始めたときのものです。試すときは、その前に②の SQL を実行して、最初の3件に戻してください。

1　? に値を入れて、1つ探す（①②③）

ProductDao.java（抜き出し）

    // ID で1つ探す。無ければ null を返す
    public Product findById(int id) throws SQLException {
        String sql = "SELECT id, name, price, stock FROM products WHERE id = ?";   // ① ?
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);   // ② 1つ目の ? に入れる
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return new Product(rs.getInt("id"), rs.getString("name"),
                                       rs.getInt("price"), rs.getInt("stock"));
                }
            }
        }
        return null;   // ③ 無かった
    }
public Product findById(int id) throws SQLException {

findById というメソッドの宣言です。引数の int id は、探したい商品の ID です。戻り値の型は Product で、見つけた商品を1つ返します。throws SQLException は、中で起きた失敗を、呼んだ側に任せるという宣言です。受け止めるのは⑧です。

String sql = "SELECT id, name, price, stock FROM products WHERE id = ?";   // ① ?

WHERE id = ? は、「id が ? の行だけ」という条件です。? は、「ここに値が入る」という空欄です。たとえの、注文書の空欄に当たります。どの ID を探すかは、あとから入れます。

try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
     PreparedStatement ps = con.prepareStatement(sql)) {
    ps.setInt(1, id);   // ② 1つ目の ? に入れる

MySQL につないで con に入れ、①の SQL を持った送る道具 ps を作ります。URL USER PASSWORD は、ProductDao の頭に書いた定数です。丸括弧の中で作ったものは、try が終わると自動で閉じます（try-with-resources）。

②の ps.setInt(1, id); で、1つ目の ? に id を入れます。1 は何番目の ? か、id は入れる値です。番号は1から数えます。配列の添え字（0から）とは違います。文字列を入れるときは setString を使います。

なぜ ? を使うのか。SQL の形を先に決めておき、値はあとから別に渡すためです。値の中に ' などの記号があっても、SQL の形は崩れません（解説2）。

try (ResultSet rs = ps.executeQuery()) {
    if (rs.next()) {
        return new Product(rs.getInt("id"), rs.getString("name"),
                           rs.getInt("price"), rs.getInt("stock"));
    }
}

SQL を実行し、返ってきた表を rs に受け取ります。try が2重なのは、? に値を入れてから実行するためです。

if (rs.next()) で1行目に進み、行があれば、その行の4つの列から Product を作って返します。id の列は主キー（同じ値が2つ無い列）なので、当てはまる行は多くても1つです。そのため、while ではなく if で1行だけ読みます。

return で途中から抜けても、rs ps con は自動で閉じます。

return null;   // ③ 無かった

当てはまる行が無かったときは、if の中に入らず、ここへ来ます。null は「何も指していない」という値で、「無かった」ことを呼んだ側に伝えます。呼んだ側は、null かどうかを確かめてから使います。

よくある間違い：null を確かめずに使う。Main の探す ID を、無い 9 に変えた形です。本番では、ID は利用者が入力した値や、別の表から取った値になります。無い ID が来ることは、必ずあります。

Main.java の⑦の所（間違いあり）

            int noteId = 9;     // 無い ID
            Product note = dao.findById(noteId);
            note.setStock(5);   // ここで止まる

noteId の 9 は探す ID で、この時点の表に ID 9 の商品はありません。findById で探した結果を note に入れ、在庫を5個に変えようとしています。

public int insert(Product p) throws SQLException {

insert は、商品を1つ追加して、変わった行数を返すメソッドです。引数の Product p は、追加する商品です。戻り値の型 int が、変わった行数です。

String sql = "INSERT INTO products (name, price, stock) VALUES (?, ?, ?)";   // ④ id は書かない

④の SQL は、products の表に行を足す INSERT です。(name, price, stock) は、値を入れる3つの列です。VALUES (?, ?, ?) の3つの ? は、順に名前・価格・在庫の空欄です。id の列は書いていません。id は、MySQL が 1, 2, 3… と自動で振ります（AUTO_INCREMENT）。なぜ id を書かないのか。Java の側で決めると、すでにある id と同じ番号を付けてしまうおそれがあるからです。

try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
     PreparedStatement ps = con.prepareStatement(sql)) {
    ps.setString(1, p.getName());   // ② 文字列は setString
    ps.setInt(2, p.getPrice());
    ps.setInt(3, p.getStock());

try の2行で、MySQL につないで con に入れ、④の SQL を持った送る道具 ps を作ります。解説1と同じです。

続く3行で、1つ目の ? に名前、2つ目に価格、3つ目に在庫を入れます。名前は文字列なので setString、価格と在庫は数なので setInt です。行の右の②は、解説1の②を指しています。

return ps.executeUpdate();   // ⑤ 変わった行数

⑤の executeUpdate() は、INSERT・UPDATE・DELETE を実行するメソッドです。戻り値は、変わった行数です。1件追加できれば、1 が返ります。SELECT の executeQuery() と違い、結果の表は返りません。return で、その行数をそのまま呼んだ側に返します。

int n = dao.insert(new Product(0, "定規", 180, 20));   // ④ id は 0 のまま
System.out.println("追加: " + n + "件");

Main の④の行では、new Product(0, "定規", 180, 20) で、追加する商品を作ります。0 は id です。SQL に id を書いていないので、この 0 は使われません。"定規" は名前、180 は価格（円）、20 は在庫（個）です。

作った商品を dao.insert(...) に渡し、返ってきた行数を n に入れます。次の行で、「追加: 1件」と表示します。返ってきた数で、うまくいったかを確かめられます（解説3）。

        String sql = "SELECT id, name, price, stock FROM products WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return new Product(rs.getInt("id"), rs.getString("name"),
                                       rs.getInt("price"), rs.getInt("stock"));
                }
            }
        }
        return null;
    }

    // 追加する。変わった行数を返す
    public int insert(Product p) throws SQLException {
        String sql = "INSERT INTO products (name, price, stock) VALUES (?, ?, ?)";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            return ps.executeUpdate();
        }
    }

    // 更新する。変わった行数を返す
    public int update(Product p) throws SQLException {
        String sql = "UPDATE products SET name = ?, price = ?, stock = ? WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            ps.setInt(4, p.getId());
            return ps.executeUpdate();
        }
    }

    // 削除する。変わった行数を返す
    public int delete(int id) throws SQLException {
        String sql = "DELETE FROM products WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            return ps.executeUpdate();
        }
    }

    // 在庫が max 個以下の商品を、ID の順に返す（自力①で足す）
    public List<Product> findByMaxStock(int max) throws SQLException {
        List<Product> list = new ArrayList<>();
        // ここに SQL を書く（在庫が ? 以下、ID の順）
        String sql = "SELECT id, name, price, stock FROM products WHERE stock <= ? ORDER BY id";
        // ここに try-with-resources を書き、? に max を入れて実行し、1行ずつ list に足す
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, max);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    list.add(new Product(rs.getInt("id"), rs.getString("name"),
                                         rs.getInt("price"), rs.getInt("stock")));
                }
            }
        }
        return list;
    }
}

言葉読み方意味
PreparedStatementぷりぺあど すてーとめんとSQL の形を先に決め、値を入れる所を ? で空けておいて送る道具。con.prepareStatement(sql) で作ります
?（プレースホルダ）ぷれーすほるだSQL の中の「ここに値が入る」という空欄。番号は SQL に出てくる順に1から数えます
setInt / setStringせっといんと / せっとすとりんぐ? に値を入れるメソッド。ps.setInt(1, id) は「1つ目の ? に id を入れる」
executeUpdate()えぐぜきゅーと あっぷでーとINSERT・UPDATE・DELETE を実行するメソッド。変わった行数を int で返します
executeQuery()えぐぜきゅーと くえりSELECT を実行するメソッド。結果の表（ResultSet）を返します（第11回）
ResultSetりざるとせっとSELECT の結果の表。rs.next() で1行ずつ進みます（第11回）
INSERTいんさーと表に行を追加する SQL。INSERT INTO products (name, price, stock) VALUES (?, ?, ?)
UPDATEあっぷでーと表の行を書き換える SQL。UPDATE products SET stock = ? WHERE id = ?
DELETEでりーと表の行を消す SQL。DELETE FROM products WHERE id = ?
WHEREうぇあSQL で、対象にする行の条件。書かないと全部の行が対象になります
AUTO_INCREMENTおーと いんくりめんと行を追加するたびに、MySQL が id を 1, 2, 3… と自動で振る設定。消した番号は使い回されません
変わった行数かわったぎょうすうexecuteUpdate() の戻り値。当てはまる行が無ければ 0 で、エラーにはなりません
SQLインジェクションえすきゅーえる いんじぇくしょん入力に ' などを含めて、SQL の形を書き換えてしまう攻撃。? で値を渡せば防げます
SQLExceptionえすきゅーえる えくせぷしょんMySQL とのやり取りで失敗したときの例外。検査例外です（第10回）
try-with-resourcesとらい うぃず りそーしずtry (...) の丸括弧の中で開いたものを、終わったときに自動で閉じる書き方
nullぬる「どの実物も指していない」ことを表す値。findById は、無ければこれを返します
NullPointerExceptionぬる ぽいんたー えくせぷしょんnull に対してメソッドを呼んだときの例外（第9回）
