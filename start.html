Javaを初めて学ぶ人へ

第2回へ進む前に知っておくと困らない、最小限の知識だけ。すでに分かる項目は読み飛ばして大丈夫です。

ここでのゴール：Javaのプログラムを1つ動かし、main、System.out.println、{ }、; の役割を説明できるようになる。

① Javaのプログラムはどう動く？

Javaは、書いた命令をそのまま文章として読むのではなく、コンピュータが実行できる形に変換してから動かします。

Javaを書く→コンパイルする→実行する→結果が出る

最初は「命令を書く → 実行する → 結果を確かめる」の繰り返しだと考えれば十分。JVMなど細かな仕組みは必要になってから覚えよう。

② まずこのコードだけ読めればOK

EclipseでMainというJavaクラスを作り、次のコードを入力します。

public class Main {
    public static void main(String[] args) {
        System.out.println("こんにちは");
    }
}

実行結果：こんにちは

public class Main は何？

Mainはクラスの名前。クラスは処理やデータをまとめる単位です。今は「このファイルにMainというJavaのプログラムを置いている」と思えばOK。ファイル名はMain.javaにします。

public static void main(String[] args) は何？

Javaの実行を始める入口となるメソッド（処理）です。最初は形を覚えるだけで大丈夫。引数・戻り値・staticは後の講義で理由を学びます。

System.out.println は何？

カッコ内に書いた文字や数値をコンソールに表示します。文字列は" "で囲みます。表示したら自動で改行されます。

{ } と ; は何？

{ }は処理のまとまりを囲みます。;は命令文の終わりに付ける印です。最初はカッコやセミコロンの付け忘れでエラーになりやすいので、同じ場所にあるか確認しましょう。

③ Eclipseで動かす最短の手順

  1. Javaプロジェクトを作成する。
  2. srcを右クリックして新規クラスMainを作る。パッケージを指定している場合は、その設定を維持してOK。
  3. Main.javaに上のコードを入力して保存。
  4. 実行ボタンまたはCtrl+F11で実行。コンソールにこんにちはが表示されたら成功。

クラスにすでにpackage ...;の行がある場合は、削除せずその下へ書きます。学校のEclipse設定によってメニュー名は少し異なります。

④ 最初によくあるエラー

「; が必要です」と出る

System.out.println("こんにちは")の最後に;があるか確認。エラーは原因の行の近くで表示されることがあります。

Mainとファイル名が合わない

public class MainはMain.javaに保存します。クラス名とファイル名の大文字・小文字を合わせます。

画面に結果が出ない

コンソールを確認します。実行したいMainを選択できているか、赤いエラー表示がないかも見ます。

⑤ 分かったか試そう

次のコードにすると、何が表示されるでしょう？

System.out.println(1 + 2);
答えと理由を見る

3。整数どうしの+は足し算。System.out.printlnが計算結果を表示します。
