① 今日の主役

Java での意味

言葉意味
データベース（MySQL）データを表（テーブル）の形でまとめて保存し、検索・追加・更新・削除を受け持つソフトです。この講座では MySQL を使います。CREATE DATABASE stock;
SQLデータベースに、データの検索・追加・更新・削除や、表の作成を命令するための言語。MySQL をはじめ、ほとんどのデータベースで共通に使えます。SELECT id, name, price, stock FROM products ORDER BY id;
JDBCJava Database Connectivity。Java のプログラムからデータベースに接続し、SQL を送って結果を受け取るための標準の仕組み（java.sql）。データベースごとのドライバ（MySQL なら Connector/J）と組み合わせて使います。Connection con = DriverManager.getConnection(URL, USER, PASSWORD);

たとえで言うと

SQL は「倉庫への注文書」、JDBC は「倉庫へつながる電話回線」

倉庫の人は、倉庫の言葉で書いた注文書しか受け付けません。

SQL は倉庫の言葉で書いた注文書、JDBC は倉庫へつながる電話回線

第10回までは、商品のデータを Java の中（List）や CSV ファイルに持っていました。今日は、データを MySQL というデータベースに置きます。商品を倉庫に預けるようなものです。

倉庫に「商品を全部、番号順に出して」と頼むときの言葉が SQL です。mysql の画面から打っても、Java から送っても、同じ SQL がそのまま通じます。

お店（Java）から倉庫（MySQL）へ注文書を届け、返事を受け取る電話回線が JDBC です。かけ方の決まりはどの倉庫でも同じで、倉庫の会社ごとの電話機に当たるのが Connector/J という部品です。

なぜ必要か

データベース（MySQL）たくさんのデータを安全に保存し、いくつものプログラムから同時に使えるようにするためです。
SQLたくさんのデータから条件に合うものを探す・並べ替えるといった仕事を、データベースに任せるためです。
JDBCJava のプログラムからデータベースを使うには、決まった手順と部品が要るからです。

Product.java　商品（第5回と同じ）

package lesson11;

public class Product {
    private static int count = 0;   // 作った商品の数（全体で1つ）

    private int id;
    private String name;
    private int price;
    private int stock;

    public Product(int id, String name, int price, int stock) {
        this.id = id;
        this.name = name;
        this.price = price;
        this.stock = stock;
        count++;
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public int getPrice() { return price; }
    public int getStock() { return stock; }

    public void setPrice(int price) {
        if (price < 0) {
            System.out.println("価格に負の値は設定できません");
            return;
        }
        this.price = price;
    }

    public void setStock(int stock) {
        if (stock < 0) {
            System.out.println("在庫に負の値は設定できません");
            return;
        }
        this.stock = stock;
    }

    public void show() {
        System.out.println(id + " / " + name + " / " + price + "円 / 残り" + stock + "個");
    }

    public static int getCount() { return count; }
}

ProductDao.java　MySQL から商品を読む係

package lesson11;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class ProductDao {
    private static final String URL = "jdbc:mysql://localhost:3306/stock";   // ⑤ つなぐ先
    private static final String USER = "root";                               // ⑤ つなぐ先
    private static final String PASSWORD = "password";                       // ⑤ つなぐ先

    public List<Product> findAll() throws SQLException {
        List<Product> list = new ArrayList<>();
        String sql = "SELECT id, name, price, stock FROM products ORDER BY id";   // ⑥ SQL を用意する
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);   // ⑦ つなぐ
             PreparedStatement ps = con.prepareStatement(sql);                    // ⑧ 送る道具を作る
             ResultSet rs = ps.executeQuery()) {                                  // ⑨ 実行する
            while (rs.next()) {                                                   // ⑩ 1行進む
                list.add(new Product(rs.getInt("id"), rs.getString("name"),       // ⑪ 詰め替える
                                     rs.getInt("price"), rs.getInt("stock")));    // ⑪ 詰め替える
            }
        }                                                                         // ⑫ ここで閉じる
        return list;
    }
}

Main.java　使うほう

package lesson11;

import java.sql.SQLException;
import java.util.List;

public class Main {

        ProductDao dao = new ProductDao();

        } catch (SQLException e) {   // ⑭ 受け止める

        }
    }
}

③ 解説

写したコードを、行の右の番号の順に説明します。説明する所のコードを、それぞれの頭に抜き出しています。よくある間違いも一緒に見ます。

1　データベースと表を作る（①②）

mysql に貼る SQL（抜き出し）

CREATE DATABASE stock DEFAULT CHARACTER SET utf8mb4;       -- ① データベースを作る
USE stock;                                                 -- ① これから使う

CREATE TABLE products (                                    -- ② 表を作る
    id     INT AUTO_INCREMENT PRIMARY KEY,
    name   VARCHAR(100) NOT NULL,
    price  INT NOT NULL,
    stock  INT NOT NULL
) DEFAULT CHARSET = utf8mb4;

CREATE DATABASE で stock という名前のデータベース（倉庫）を作り、USE stock; でこれから使うと指定します。utf8mb4 は文字コードの指定で、日本語の商品名がそのまま入ります。データベースの名前の stock と、在庫の列 stock は別物です。

CREATE TABLE で表（テーブル）を作ります。id INT のように「列の名前と型」を並べます。VARCHAR(100) は最大100文字の文字列、NOT NULL は「空を許さない」です。id の AUTO_INCREMENT PRIMARY KEY は「番号を自動で振り、その行を1つに決める列」です。

なぜ列を決めておくのか。列と型を決めておくと、MySQL が型を守ってくれます。列は Product のフィールドと同じ4つにしてあるので、表の1行が Product 1つになります。

2　行を入れて、取り出す（③④）

mysql に貼る SQL（抜き出し）

INSERT INTO products (name, price, stock) VALUES           -- ③ 3件入れる
    ('ボールペン', 150, 30),
    ('ノート', 220, 10),
    ('消しゴム', 100, 50);

SELECT id, name, price, stock FROM products ORDER BY id;   -- ④ 取り出す

INSERT は「表に行を入れる」SQL です。丸括弧の列の順に値を並べ、文字列は 'ボールペン' のようにシングルクォートで囲みます。id は書きません。②の AUTO_INCREMENT が 1・2・3 と振るので、番号がぶつかりません。

SELECT は「表から取り出す」SQL です。「products から、4つの列を、id の小さい順に」と読みます。mysql の画面で3件入ったことを確かめる文で、同じ文を⑥で Java から送ります。

4　SQL を用意して、つないで、実行する（⑥〜⑨）

ProductDao.java（抜き出し）

⑥〜⑫は、JDBC で表を読むときに毎回同じ順で書く手順です。⑥で、送る SQL を文字列で用意します。④と同じ文で、最後の ; は付けません。⑦の DriverManager.getConnection で MySQL につなぎ、つながりを表す Connection を受け取ります。つながらなければ、ここで SQLException が起きます。⑧で、⑥の SQL を持った送る道具 PreparedStatement を作ります。⑨の executeQuery() で実行し、返ってきた表を ResultSet として受け取ります。

なぜ SQL に ORDER BY を書くのか。書かないと、並び順は決まらないからです。ORDER BY price DESC と書けば価格の高い順になります。並べ替えは MySQL がするので、Java 側は変わりません。

④で使う WHERE と、SQL の「等しい」。写したコードには出てきませんが、④では WHERE で行を絞ります。ID が 2 の商品だけを取り出そうとして WHERE を足し、Java の癖で == と書いた形です。

5　1行ずつ読んで、閉じる（⑩〜⑫）

ProductDao.java（抜き出し）

    public List<Product> findAll() throws SQLException {
        // （中略）
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);   // ⑦ つなぐ
             PreparedStatement ps = con.prepareStatement(sql);                    // ⑧ 送る道具を作る
             ResultSet rs = ps.executeQuery()) {                                  // ⑨ 実行する
            while (rs.next()) {                                                   // ⑩ 1行進む
                list.add(new Product(rs.getInt("id"), rs.getString("name"),       // ⑪ 詰め替える
                                     rs.getInt("price"), rs.getInt("stock")));    // ⑪ 詰め替える
            }
        }                                                                         // ⑫ ここで閉じる
        return list;
    }

⑩の rs.next() は、rs が見ている行を1つ進めます。進めた先に行があれば true、もう無ければ false です。rs は最初、1行目の「手前」を見ているので、next() で1行目に進んでから読みます。3行なら3回回って止まります。

ResultSet は「いま見ている行」を持っていて、next() で1行ずつ進む

⑪は、いま見ている行から、列の名前を指定して値を取り出します。INT の列は getInt、文字の列は getString です。表の1行を Product 1つに詰め替えて list に入れるので、Java の側は第8回からの List<Product> のまま使えます。

⑫の } で、try の丸括弧で作った3つ（rs ps con）が自動で閉じられます。第10回の try-with-resources です。なぜ閉じるのか。回線を切り忘れると、MySQL がつなげる数の上限に達して、誰もつなげなくなるからです。

よくある間違い：next() を呼ぶ前に読む。「1件目だけ欲しい」と考えて、while (rs.next()) を消した形です。

実行結果

データベースのエラー: Before start of result set

Before start of result set は「結果の表の、始まりより前」という意味です。1行目の手前には値が無いので、読めません。読む前に必ず next() を呼びます。全部の行なら while (rs.next())、1行だけなら if (rs.next()) です。

列の名前を "nane" のように打ち間違えても、赤い波線は出ずにコンパイルが通ります。Java から見るとただの文字列だからです。実行すると Column 'nane' not found. と出ます。メッセージに出ている名前を、コードの中で探すのが早道です。

            }
            System.out.println("全部で" + products.size() + "件です");
        } catch (SQLException e) {   // ⑭ 受け止める
            System.out.println("データベースのエラー: " + e.getMessage());
        }
    }

⑬で ProductDao に「全部読んで」と頼み、List<Product> を受け取ります。なぜ ProductDao に分けるのか。Main に SQL や JDBC を書かずに済ませるためです。MySQL とのやりとりは ProductDao が1か所で引き受けます。

⑭は、データベースで起きた例外 SQLException を受け止めて、理由を表示します。findAll に throws SQLException と書いてあるので、呼んだ側が受け止めます（第10回の検査例外）。書かないとコンパイルエラーです。

LowStockDao.java

package lesson11;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class LowStockDao {
    private static final String URL = "jdbc:mysql://localhost:3306/stock";
    private static final String USER = "root";
    private static final String PASSWORD = "password";

    public List<Product> findLowStock() throws SQLException {
        List<Product> list = new ArrayList<>();
        // ここに、在庫が30個以下の商品を、在庫の少ない順に取り出す SQL を書く
        String sql = "SELECT id, name, price, stock FROM products WHERE stock <= 30 ORDER BY stock";
        // ここに、ProductDao の findAll と同じ手順で、つないで・実行して・詰め替える処理を書く
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                list.add(new Product(rs.getInt("id"), rs.getString("name"),
                                     rs.getInt("price"), rs.getInt("stock")));
            }
        }
        return list;
    }
}
