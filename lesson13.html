① 今日の主役

Java での意味

言葉意味
DTOData Transfer Object。データベースの1行分などの値をまとめて持ち、クラスの間で受け渡すためだけのクラス。フィールドとコンストラクタ、getter・setter だけを持ちます。new ProductDTO(2, "ノート", 240, 15)
DAOData Access Object。データベースとのやりとり（SQL の実行）だけを受け持つクラス。ほかのクラスは SQL を書かず、DAO のメソッドを呼びます。dao.findAll()
3層（Service）プログラムを、窓口（プレゼンテーション層）・判断をする Service（ビジネスロジック層）・データベースとやりとりする DAO（データアクセス層）の3つに分ける形です。呼ぶ向きは、窓口 → Service → DAO の一方通行です。ProductService service = new ProductService(); service.add(pad);

たとえで言うと

DAO は「倉庫係」、DTO は「商品を入れて運ぶ箱」

倉庫係は、言われた物を出し入れするだけです。売ってよいかは店長が決めます。

窓口・店長・倉庫係は、それぞれ自分の仕事だけをする。間を行き来するのは箱

店には3つの持ち場があります。お客さんと話す窓口、受けてよい注文かを決める店長、棚から出し入れする倉庫係です。窓口は倉庫に入りません。倉庫係は値段を決めません。

Java でも同じように分けます。倉庫（MySQL）との出し入れだけをするクラスが DAO です。今日の ProductDAO がこれです。

持ち場の間を行き来するのは、商品1件分の値を入れた箱です。これが DTO です。今日の ProductDTO がこれです。

今日新しく作るのは、店長にあたる ProductService です。窓口は店長にだけ頼み、店長が倉庫係に頼みます。この3つの持ち場の分け方を3層と言います。

なぜ必要か

DTO1件分の値をひとまとめにして渡せば、クラスの間のやりとりが単純になるからです。
DAOSQL をこの1か所に閉じ込めて、ほかのクラスがデータベースを気にせずに済むようにするためです。SQL や接続先を直すのは DAO だけです。
3層（Service）役割を分けておくと、窓口を画面に変えても判断の処理はそのまま使え、直す場所もすぐ分かるからです。

package lesson13;

public class ProductDTO {                                       // ① DTO
    private int id;
    private String name;
    private int price;
    private int stock;

    public ProductDTO(int id, String name, int price, int stock) {
        this.id = id;
        this.name = name;
        this.price = price;
        this.stock = stock;
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public int getPrice() { return price; }
    public int getStock() { return stock; }

    public void setPrice(int price) { this.price = price; }     // ② 検査しない
    public void setStock(int stock) { this.stock = stock; }     // ② 検査しない
}

ProductDAO.java　倉庫係

package lesson13;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class ProductDAO {                                       // ③ DAO
    private static final String URL = "jdbc:mysql://localhost:65534/stock";
    private static final String USER = "root";
    private static final String PASSWORD = "pass";

    // 全部の商品を読む（第11回と同じ）
    public List<ProductDTO> findAll() throws SQLException {
        List<ProductDTO> list = new ArrayList<>();
        String sql = "SELECT id, name, price, stock FROM products ORDER BY id";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                list.add(new ProductDTO(rs.getInt("id"), rs.getString("name"),  // ④ 1行を DTO に詰める
                                        rs.getInt("price"), rs.getInt("stock")));
            }
        }
        return list;
    }

    // ID で1つ探す。無ければ null を返す
    public ProductDTO findById(int id) throws SQLException {
        String sql = "SELECT id, name, price, stock FROM products WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return new ProductDTO(rs.getInt("id"), rs.getString("name"),
                                          rs.getInt("price"), rs.getInt("stock"));
                }
            }
        }
        return null;
    }

    // 追加する。変わった行数を返す
    public int insert(ProductDTO p) throws SQLException {
        String sql = "INSERT INTO products (name, price, stock) VALUES (?, ?, ?)";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            return ps.executeUpdate();
        }
    }

    // 更新する。変わった行数を返す
    public int update(ProductDTO p) throws SQLException {
        String sql = "UPDATE products SET name = ?, price = ?, stock = ? WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            ps.setInt(4, p.getId());
            return ps.executeUpdate();
        }
    }

    // 削除する。変わった行数を返す
    public int delete(int id) throws SQLException {
        String sql = "DELETE FROM products WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            return ps.executeUpdate();
        }
    }
}

ProductService.java　店長（今日作る）

package lesson13;

import java.sql.SQLException;
import java.util.List;

public class ProductService {
    private ProductDAO dao = new ProductDAO();                  // ⑤ DAO を持つ

    public List<ProductDTO> findAll() throws SQLException {
        return dao.findAll();
    }

    public void add(ProductDTO p) throws SQLException {
        check(p);                                               // ⑥ 先に検査
        dao.insert(p);
    }

    public void update(ProductDTO p) throws SQLException {
        check(p);
        if (dao.update(p) == 0) {
            throw new IllegalArgumentException("ID " + p.getId() + " の商品はありません");
        }
    }

    public void delete(int id) throws SQLException {
        if (dao.delete(id) == 0) {
            throw new IllegalArgumentException("ID " + id + " の商品はありません");
        }
    }

    private void check(ProductDTO p) {
        if (p.getName() == null || p.getName().isBlank()) {
            throw new IllegalArgumentException("商品名を入力してください");  // ⑦ 例外で断る
        }
        if (p.getPrice() < 0) {
            throw new IllegalArgumentException("価格に負の値は設定できません");
        }
        if (p.getStock() < 0) {
            throw new IllegalArgumentException("在庫に負の値は設定できません");
        }
    }
}

Main.java　窓口

package lesson13;

import java.sql.SQLException;

public class Main {
    public static void main(String[] args) throws SQLException {
        ProductService service = new ProductService();          // ⑧ Service だけを使う
        ProductDTO pad = new ProductDTO(0, "付箋", 200, 25);    // ⑨ 箱に詰める

        try {
            service.add(pad);
            System.out.println(pad.getName() + "を登録しました");
        } catch (IllegalArgumentException e) {                  // ⑩ 断られたとき
            System.out.println("登録できません: " + e.getMessage());
        }

        for (ProductDTO p : service.findAll()) {
            System.out.println(p.getId() + " / " + p.getName() + " / " + p.getPrice()
                    + "円 / 残り" + p.getStock() + "個");
        }
    }
}

ProductDTO.java のクラスの行です。DTO（Data Transfer Object）は、商品1件分の値を持って運ぶだけのクラスです。

setPrice は価格を、setStock は在庫を入れ直す setter です。setter は、フィールドに値を入れるメソッドです（第5回）。

2つの setter は、受け取った値をそのまま入れます。「負の値なら入れない」のような検査はしません。なぜ検査しないのか。検査は店長（Service）の仕事にまとめるためです。箱にも検査があると、同じ検査が2か所に分かれます。すると、片方だけ直す事故が起きやすくなります。
