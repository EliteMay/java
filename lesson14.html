① 今日の主役

Java での意味

言葉意味
SwingJava で画面（ウィンドウ・ボタン・入力欄・表など）を作るための部品の集まりです（javax.swing）。JFrame がウィンドウ、JButton がボタン、JTextField が入力欄です。JButton addButton = new JButton("追加");
部品の配置（レイアウト）画面の部品をどこにどう並べるかを決める仕組みです。BorderLayout は上・下・真ん中などに、GridLayout は格子状に並べます。JPanel form = new JPanel(new GridLayout(4, 2)); add(form, BorderLayout.NORTH);
イベントボタンが押された、など利用者の操作によって起きる出来事。Swing では、イベントが起きたときに動かす処理（リスナー）を、部品にあらかじめ登録しておきます。addButton.addActionListener(e -> addProduct());

たとえで言うと

ボタンは「呼び鈴」、addActionListener は「鳴ったらこうする」の貼り紙

押される前に、押されたら何をするかを貼っておきます。

ボタンは「呼び鈴」、addActionListener は「鳴ったらこうする」の貼り紙

これまでのプログラムは、main の上から順に動いて終わりました。画面のあるプログラムは違います。画面を出したあとは、利用者が何かするのを待ちます。

ボタンが押された、という知らせをイベントと言います。ボタンは呼び鈴のようなもので、押されると鳴りますが、自分では何もしません。

そこで、起動したときに「鳴ったらこうする」という貼り紙を貼っておきます。これが addActionListener です。貼った時点では何も起きません。押されたときに初めて、貼り紙に書いた処理が動きます。

玄関そのものがウィンドウ（JFrame）。取り付ける部品の集まりが Swing、どこに付けるかを決める配置図がレイアウト

呼び鈴や表示板のように、画面に取り付ける部品の集まりが Swing です。表示板が JLabel、部品を取り付ける玄関そのものがウィンドウの JFrame です。どの部品を玄関のどこに取り付けるかを決める配置図に当たるのが、部品の配置（レイアウト）です。

たとえJava では
呼び鈴ボタン　JButton
呼び鈴が鳴るイベント（ボタンが押された、という知らせ）
「鳴ったらこうする」の貼り紙addButton.addActionListener(e -> addProduct());
貼り紙に書いた用事addProduct() の中身
玄関そのものウィンドウ　JFrame
表示板文字を出す部品　JLabel
呼び鈴や表示板などの部品Swing　JLabel JButton JTextField
部品をどこに付けるかの配置図レイアウト　BorderLayout GridLayout

なぜ必要か

Swingコンソールではなく、ボタンや入力欄で操作できる画面を作るためです。
部品の配置（レイアウト）画面の大きさが変わっても、部品の並びが崩れないようにするためです。
イベント画面のプログラムでは、利用者がいつ何をするか分からないので、「起きたら動く」形で書く必要があるからです。

public class ProductDTO {

ProductDAO.java　MySQL を読み書きする倉庫係（第13回と同じ）

package lesson14;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class ProductDAO {
    private static final String URL = "jdbc:mysql://localhost:65534/stock";
    private static final String USER = "root";
    private static final String PASSWORD = "pass";

    // 全部の商品を読む（第11回と同じ）
    public List<ProductDTO> findAll() throws SQLException {
        List<ProductDTO> list = new ArrayList<>();
        String sql = "SELECT id, name, price, stock FROM products ORDER BY id";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                list.add(new ProductDTO(rs.getInt("id"), rs.getString("name"),
                                        rs.getInt("price"), rs.getInt("stock")));
            }
        }
        return list;
    }

    // ID で1つ探す。無ければ null を返す
    public ProductDTO findById(int id) throws SQLException {
        String sql = "SELECT id, name, price, stock FROM products WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return new ProductDTO(rs.getInt("id"), rs.getString("name"),
                                          rs.getInt("price"), rs.getInt("stock"));
                }
            }
        }
        return null;
    }

    // 追加する。変わった行数を返す
    public int insert(ProductDTO p) throws SQLException {
        String sql = "INSERT INTO products (name, price, stock) VALUES (?, ?, ?)";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            return ps.executeUpdate();
        }
    }

    // 更新する。変わった行数を返す
    public int update(ProductDTO p) throws SQLException {
        String sql = "UPDATE products SET name = ?, price = ?, stock = ? WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, p.getName());
            ps.setInt(2, p.getPrice());
            ps.setInt(3, p.getStock());
            ps.setInt(4, p.getId());
            return ps.executeUpdate();
        }
    }

    // 削除する。変わった行数を返す
    public int delete(int id) throws SQLException {
        String sql = "DELETE FROM products WHERE id = ?";
        try (Connection con = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);
            return ps.executeUpdate();
        }
    }
}

ProductService.java　検査をする店長（第13回と同じ）

package lesson14;

import java.sql.SQLException;
import java.util.List;

public class ProductService {
    private ProductDAO dao = new ProductDAO();

    public List<ProductDTO> findAll() throws SQLException {
        return dao.findAll();
    }

    public void add(ProductDTO p) throws SQLException {
        check(p);
        dao.insert(p);
    }

    public void update(ProductDTO p) throws SQLException {
        check(p);
        if (dao.update(p) == 0) {
            throw new IllegalArgumentException("ID " + p.getId() + " の商品はありません");
        }
    }

    public void delete(int id) throws SQLException {
        if (dao.delete(id) == 0) {
            throw new IllegalArgumentException("ID " + id + " の商品はありません");
        }
    }

    private void check(ProductDTO p) {
        if (p.getName() == null || p.getName().isBlank()) {
            throw new IllegalArgumentException("商品名を入力してください");
        }
        if (p.getPrice() < 0) {
            throw new IllegalArgumentException("価格に負の値は設定できません");
        }
        if (p.getStock() < 0) {
            throw new IllegalArgumentException("在庫に負の値は設定できません");
        }
    }
}

ProductFrame.java　今日作る画面

package lesson14;

import java.awt.BorderLayout;
import java.awt.GridLayout;
import java.sql.SQLException;

import javax.swing.JButton;
import javax.swing.JFrame;
import javax.swing.JLabel;
import javax.swing.JOptionPane;
import javax.swing.JPanel;
import javax.swing.JScrollPane;
import javax.swing.JTable;
import javax.swing.JTextField;
import javax.swing.table.DefaultTableModel;

public class ProductFrame extends JFrame {                                            // ① 画面そのもの
    private ProductService service = new ProductService();                            // 第13回の ProductService
    private DefaultTableModel model =
            new DefaultTableModel(new String[] {"ID", "商品名", "価格", "在庫"}, 0);  // ② 表の中身
    private JTable table = new JTable(model);                                         // ② 表の見た目

    private JTextField idField = new JTextField();                                    // ③ 入力欄
    private JTextField nameField = new JTextField();                                  // ③ 入力欄
    private JTextField priceField = new JTextField();                                 // ③ 入力欄
    private JTextField stockField = new JTextField();                                 // ③ 入力欄

    public ProductFrame() {
        setTitle("商品在庫管理");
        setSize(480, 360);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);     // ④ ×で終わる
        setLocationRelativeTo(null);

        JPanel form = new JPanel(new GridLayout(4, 2));     // ⑤ 4行2列に並べる
        form.add(new JLabel("ID（更新・削除で使う）"));
        form.add(idField);
        form.add(new JLabel("商品名"));
        form.add(nameField);
        form.add(new JLabel("価格"));
        form.add(priceField);
        form.add(new JLabel("在庫"));
        form.add(stockField);

        JButton addButton = new JButton("追加");
        JButton updateButton = new JButton("更新");
        JButton deleteButton = new JButton("削除");
        JPanel buttons = new JPanel();
        buttons.add(addButton);
        buttons.add(updateButton);
        buttons.add(deleteButton);

        add(form, BorderLayout.NORTH);                      // ⑤ 上
        add(new JScrollPane(table), BorderLayout.CENTER);   // ⑤ 真ん中
        add(buttons, BorderLayout.SOUTH);                   // ⑤ 下

        addButton.addActionListener(e -> addProduct());     // ⑥ イベント
        showList();                                         // ⑦ 最初の一覧
    }

    private void addProduct() {                             // ⑧ 押されたときの処理
        try {
            String name = nameField.getText();
            int price = Integer.parseInt(priceField.getText());
            int stock = Integer.parseInt(stockField.getText());
            service.add(new ProductDTO(0, name, price, stock));  // Service が検査してから登録する
            showList();
        } catch (NumberFormatException e) {
            JOptionPane.showMessageDialog(this, "価格と在庫は数字で入力してください");
        } catch (IllegalArgumentException e) {
            JOptionPane.showMessageDialog(this, e.getMessage());  // Service が断った理由
        } catch (SQLException e) {
            JOptionPane.showMessageDialog(this, "データベースのエラー: " + e.getMessage());
        }
    }

    private void showList() {                               // ⑦ 一覧を表示し直す
        model.setRowCount(0);                               // いったん全部消す
        try {
            for (ProductDTO p : service.findAll()) {
                Object[] row = {p.getId(), p.getName(), p.getPrice(), p.getStock()};
                model.addRow(row);
            }
        } catch (SQLException e) {
            JOptionPane.showMessageDialog(this, "データベースのエラー: " + e.getMessage());
        }
    }
}

            int price = Integer.parseInt(priceField.getText());
            int stock = Integer.parseInt(stockField.getText());
            service.add(new ProductDTO(0, name, price, stock));  // Service が検査してから登録する
            showList();
        } catch (NumberFormatException e) {
            JOptionPane.showMessageDialog(this, "価格と在庫は数字で入力してください");
        } catch (IllegalArgumentException e) {
            JOptionPane.showMessageDialog(this, e.getMessage());  // Service が断った理由
        } catch (SQLException e) {
            JOptionPane.showMessageDialog(this, "データベースのエラー: " + e.getMessage());
        }
    }

    private void updateProduct() {
        // ここに、4つの入力欄を読み、service.update で書き換える処理を書く
        try {
            int id = Integer.parseInt(idField.getText());
            String name = nameField.getText();
            int price = Integer.parseInt(priceField.getText());
            int stock = Integer.parseInt(stockField.getText());
            service.update(new ProductDTO(id, name, price, stock));
            showList();
        } catch (NumberFormatException e) {
            JOptionPane.showMessageDialog(this, "ID と価格と在庫は数字で入力してください");
        } catch (IllegalArgumentException e) {
            JOptionPane.showMessageDialog(this, e.getMessage());
        } catch (SQLException e) {
            JOptionPane.showMessageDialog(this, "データベースのエラー: " + e.getMessage());
        }
    }

    private void deleteProduct() {
        // ここに、ID の入力欄を読み、service.delete で消す処理を書く
        try {
            int id = Integer.parseInt(idField.getText());
            service.delete(id);
            showList();
        } catch (NumberFormatException e) {
            JOptionPane.showMessageDialog(this, "ID は数字で入力してください");
        } catch (IllegalArgumentException e) {
            JOptionPane.showMessageDialog(this, e.getMessage());
        } catch (SQLException e) {
            JOptionPane.showMessageDialog(this, "データベースのエラー: " + e.getMessage());
        }
    }

    private void showList() {
        model.setRowCount(0);                               // いったん全部消す
        try {
            for (ProductDTO p : service.findAll()) {
                Object[] row = {p.getId(), p.getName(), p.getPrice(), p.getStock()};
                model.addRow(row);
            }
        } catch (SQLException e) {
            JOptionPane.showMessageDialog(this, "データベースのエラー: " + e.getMessage());
        }
    }
}

コンストラクタの2行が貼り紙で、updateProduct() と deleteProduct() が貼り紙に書いた用事です。

ProductDTO・ProductDAO・ProductService は1行も変えていません。画面は「入力欄を読む・Service に頼む・結果を見せる」だけで、検査も SQL も書いていません。第13回の3層の窓口が、コンソールの Main から画面に替わっただけです。
