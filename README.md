# Java 学習教材

**公開サイト：** https://elitemay.github.io/java/

## 内容
- 元教材の第2〜11回（10講義）をそのまま収録：`lesson02.html`〜`lesson11.html`
- 元問題集：`problems.html`
- 講義一覧：`index.html`
- GitHub Pages自動公開：`.github/workflows/deploy.yml`

## 元教材からの変更点
- **本文・コード・演習・解答は変更していません**。元ZIPとのテキスト比較では、改行コードを揃えたうえで全10講義・問題集の本文が一致しました。
- 講義一覧ページを新設し、前後の講義や問題集への移動リンクを追加。
- 元の「白い背景・オレンジの見出し・暗色コード欄」は維持。
- `reader.css`：見出し・注意枠のマーカーラインを強調し、コードの文字サイズ・行間・背景色のコントラストを調整。
- `reader.js`：Java・SQLコードのキーワード/型/文字列/数値を色分け。コード欄の行をマウスでポイントすると強調、クリックで固定、再クリック・Escで解除。
- 元からあるコードコピー、文字拡大、解答表示機能は維持（Javaの実行環境はサイトにありません）。

## 実装
静的HTML + 共通CSS/JavaScript。依存ライブラリなし。各講義は元の資料のマークアップと図解を尊重した構成です。

## 公開と検証
`main`へのpushでGitHub Pagesへデプロイ。公開の可否と動作確認結果はGitHub Actionsと実際のページで確認してください。実ブラウザのすべての操作・全Javaプログラムのコンパイル実行までは自動検証対象ではありません。
