# Java 学習ノート

学校教材（第2〜11回）と問題集をもとに、短い説明と動くコードで理解する復習サイト。

## 使い方

`index.html` をブラウザで開くか GitHub Pages で公開してください。外部ライブラリやビルドは不要です。

- 左の目次で講義を選択
- 要点→コード→実行結果→ミニ問題の順に学ぶ
- 解答はボタンで表示。進捗はブラウザに保存され、JSONで書き出し・読み込みが可能

## 対象

Java の変数・条件分岐・配列・メソッド・クラス・static・継承・インタフェース・コレクション・例外・ファイル入出力・SQL/JDBC。

元教材の丸写しではなく、理解優先で独自に要約。問題集の文章は簡潔に再構成しています。JDBCのコードはMySQLとドライバを別途準備する必要があります。

## 検証

静的構文チェックを行い、ブラウザ上の実操作・GitHub Pages 公開確認は別途必要です。
