# Java 学習教材

**公開サイト:** https://elitemay.github.io/java/

## 方針
授業の元教材を正本として、説明・コード例・Eclipseの操作手順・演習・解答を基本的に保持した復習サイト。重複する長い導入の一部を整理し、講義間ナビゲーションを追加しました。配色は元教材の白背景・オレンジのアクセント・濃色コード欄を維持しています。

## 収録内容
- 第2〜11回（`lesson02.html`〜`lesson11.html`、10講義）
- 元の問題集（`problems.html`）
- 講義一覧（`index.html`）

## 開き方
公開サイトをブラウザで開き、講義か問題集を選んでください。GitHub Pagesの公開は `.github/workflows/deploy.yml` で自動化しています。HTMLのみで動作し、ビルドは不要です。

## 注意
古い試作版の `app.js` / `lessons.js` / `deep-dives.js` / `style.css` は現在の公開入口から参照していません。正本は上記の元教材ベースHTMLです。

## 確認
GitHub Pagesの講義一覧がHTTP 200で閲覧可能なことを確認。各講義のEclipse実行や問題集の全問題を実際に解く検証は別途必要です。
